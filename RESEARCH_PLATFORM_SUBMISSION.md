Recommended platforms

1. ResearchGate

ResearchGate is for researcher profiles, institutional affiliations, publications, and unpublished research. Add AQIRI as an affiliation on official researcher profiles, then add publications or project pages and link to https://aqiri.org/.

Suggested affiliation:

Al-Qamar Islamic Research Institute (AQIRI)

Suggested department:

Academic Publishing and Research Development

2. Academia.edu

Create a researcher/profile account, add AQIRI as the affiliation, add research interests, upload permitted papers or reports, and add the official website link.

3. Zenodo

Use Zenodo for citable research outputs. Upload PDFs, datasets, conference proceedings, books, reports, or presentations. Zenodo can assign a DOI to each published upload.

Suggested community name:

Al-Qamar Islamic Research Institute

4. OSF

Use OSF for research projects, open materials, preprints, datasets, and collaborative academic project pages. Add the AQIRI website as the project homepage link.

5. ORCID

Create ORCID records for individual scholars. Add AQIRI as employment/affiliation and add the website link.

6. Google Scholar

Google Scholar does not index a normal institutional website like a search engine. It indexes scholarly papers. Create author profiles for AQIRI scholars and link publications where available.

7. ROR

If AQIRI is not listed in the Research Organization Registry, submit an organization request. ROR helps research systems identify institutions consistently.

Important upload rules

- Do not upload journal articles or books unless AQIRI owns the rights or the author/publisher license permits it.
- Upload PDFs only when you have permission.
- Use the website link in every profile.
- Use the exact same institution name everywhere: Al-Qamar Islamic Research Institute.
- Use the same short name everywhere: AQIRI.
